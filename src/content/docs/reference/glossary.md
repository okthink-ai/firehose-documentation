Look up a term as you encounter it, then return to the guide you were following.

| Term | Meaning in these guides |
| --- | --- |
| Agent | The coding assistant doing the work and responding to your requests |
| Provider | The agent integration selected when you start a session |
| Model | The model option selected for that provider |
| Session | A conversation and its associated agent runtime |
| Turn | One period of agent work in response to input; a task can span several turns |
| Project | The repository you choose to work on |
| Repository | Files and their Git history |
| Workspace | The directory and branch selected for a session |
| Checkout | The working files for a particular Git branch or revision |
| Worktree | An additional checkout with its own directory, sharing a repository’s Git history |
| Branch | A named line of development in Git |
| Diff | Differences between versions of files |
| Commit | A recorded snapshot of changes in Git |
| Staged | Changes prepared in Git’s index for the next commit |
| Unstaged | Tracked file edits not currently staged |
| Untracked | A file Git is not tracking yet |
| Questionnaire | A structured set of clarifying questions shown in Questions |
| Server | The machine and Firehose service running your projects and agent sessions |
| Tailnet | The Tailscale network your devices use to reach one another |

For a task-oriented map, see [What you can do](/what-you-can-do/). For the controls themselves, see [Find the right tool](/tools/overview/).
