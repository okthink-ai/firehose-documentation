Find a walkthrough for a whole job, from the first idea to merged work, or for recovering when something went wrong. Each help article strings together the tools described elsewhere in these guides and links to them for detail.

- **[Take a feature from plan to merge](/help/feature-workflow/)**
  Plan a feature in Firehose or start from a GitHub issue, clarify it with **Ask me questions**, build it in its own worktree, review it with **Smart Review** and **X-Ray**, test it, and hand it off.
- **[Recover from lost messages and ended sessions](/help/recover-session-problems/)**
  Tell whether a message cleared without reaching a Claude Code agent or a session ended on its own, update Firehose to the release that fixes it, and pick up the lost work.
